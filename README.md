# KITIED
Персональный сайт Романа Кытина. React, Vite, SCSS, GSAP и i18next. Переключение RU/EN сохраняется в браузере. При включённом reduced motion прокрутка и появление секций работают без анимации.

## Локальный запуск
Требуется Node.js 22.12+ или 24.

```sh
npm ci
npm run dev
```

## Сборка
```sh
npm run build
npm run preview
```

## GitHub Pages
Исходники размещаются в main. Для публикации загрузите содержимое dist в корень ветки gh-pages, добавьте пустой файл .nojekyll и выберите эту ветку и папку /(root) в Settings → Pages → Deploy from a branch. Относительные пути позволяют разместить сайт в подпапке репозитория.

Тексты обеих локалей находятся в src/content.js. Иллюстрация геймдева изображает архитектурный блокинг. В кейсе Shiftly использован экран с демонстрационными данными.
